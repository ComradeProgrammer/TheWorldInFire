# BALTAP 1983

BALTAP 1983 是一个七回合的入门剧本，战场集中在丹麦及波罗的海进出口地区。

第一回合的联合增援阶段自动完成开局部署：十七个单位直接放置到地图格，十个单位放入各自阵营的战略预备队。

之后到达的单位同样在联合增援阶段自动进入战略预备队：

| 回合 | 新增单位数 |
| --- | ---: |
| 2 | 11 |
| 3 | 2 |
| 4 | 2 |
| 5 | 1 |
| 6 | 1 |
| 7 | 0 |

空运司令部：华约三个，NATO 一个。

空中力量：双方每回合各获得一个战术空中点数，另有一个额外的战术空中点数，可在自选的任意一个回合使用。双方都没有战役空中点数。

奇袭：北约在第一回合遭受奇袭，因此华约当回合的空中打击骰子加一，华约的进攻向上移动一栏。

北德前线（NEGF）HQ：为北德前线和近卫坦克第 2 集团军的单位提供华约的进攻支援。它不能移动，并在第四回合开始时移出游戏。本剧本中，波罗的海前线 HQ、波罗的海军 HQ 和北约的 HQ 都不提供进攻支援。

所有七个回合结束后，游戏结束。
