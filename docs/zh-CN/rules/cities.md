# 城市

城市分为小城市、大型城市和关键城市三类。每个城市格始终由一方控制。

## 自由城市与被征服城市

游戏开始时，每个城市由其所属一方控制，称为**自由城市**。东德、波兰和捷克斯洛伐克的城市属于华约；其余所有城市（包括西柏林）属于 NATO。

由另一方占据的城市称为**被征服城市**。原始拥有方重新夺回后，它会重新成为自由城市。

## 移动与城市

- 任何单位都不能以任何移动方式进入敌方自由城市，即使城中没有敌方单位。
- 单位只能通过战术移动进入敌方被征服城市。它会取得所进入的每个敌方被征服城市的控制权，即使没有在该城停下。如果该城市原本属于移动方，则城市被解放，重新成为自由城市。
- 行军移动和铁路移动不能进入敌方控制的城市。
- 空运不能停在敌方控制的城市。
- 自由城市只对自身所在格施加控制区。
- 己方自由城市与己方单位一样，允许软目标单位从另一个敌控格直接进入该格。

撤销一次移动时，该移动夺取的城市控制权也会一并恢复。

## 攻击目标

敌方自由城市即使没有敌方单位驻守，也可以被设为攻击目标。
