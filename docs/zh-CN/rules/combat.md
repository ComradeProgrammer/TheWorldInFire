# 战斗

在战斗阶段，行动方用相邻的机动单位攻击敌方控制的格子。每次攻击针对一个**目标格**，作为一场战斗结算。进攻投入后，防守方可以让一个相邻单位**反应**进入该格（见[反应](#反应)）；防守方的其他应对遵循下述固定规则。

## 选择目标格

目标格必须有敌方单位或敌方自由城市，或者是放有己方突破标记的空格。

- **华约**只能攻击在战斗计划阶段设为攻击目标的格子，以及有突破标记的格子。在结束阶段前，必须攻击所有仍能攻击的已标记目标。
- **北约**可以攻击任何合格的格子；其标记的目标是可选的。
- 同一阶段内，任何格子不能被攻击两次，任何单位也不能进攻两次。

## 投入单位

与目标格相邻的任何己方机动单位都可以进攻，但以下单位除外：

- HQ，永远不能进攻；
- 炮兵师，只通过炮兵打击作战（见[炮兵](artillery.md)）；
- 处于铁路标记下的单位；
- 预备队单位（见[预备队](reserve.md)）；
- 需要跨越阻断格边、全海格边或丹麦渡轮进攻的单位。

攻击力为 0 的单位可以参与进攻，但不能单独进攻。

## 进攻支援

投入进攻时，进攻方可以让一个合格的 HQ 提供**进攻支援**，使战斗比向上移动一栏。剧本规定哪些 HQ 可以提供支援，以及各自指挥哪些编制。该 HQ：

- 必须有补给，未被压制，且不在铁路标记下；
- 每个战斗阶段只能支援一场战斗；
- 必须能在其支援范围内到达至少一个所投入的本编制单位。路径不能经过敌方单位、敌方控制的城市、没有己方单位的敌控格、全海格或全海格边，也不能跨越阻断格边（丹麦渡轮可以）。计算格数时计入 HQ 所在格，不计入单位所在格。

一场战斗只能得到一个 HQ 的支援。HQ 本身不参与战斗，也不受战斗结果影响。

## 反应

进攻一经投入即不可更改：进攻方之后不能增加或撤回单位，也不能更改进攻支援。在战斗结算之前，防守方可以把**一个**机动单位从相邻格移入目标格。反应的单位随后与格中原有单位一同防守，并承受相同的战斗结果。

单位只有满足以下全部条件才能反应：

- 是机动单位（不是 HQ 或炮兵师），且不在铁路标记下；
- 未混乱，并具有移动补给和战斗补给；
- 本阶段尚未在任何战斗中防守过；
- 不需要跨越大河、堤道、阻断或全海格边，也不经由丹麦渡轮；
- 进入后目标格不超出堆叠上限。

此外：

- 任何单位都不能反应进入山地格，也不能进入只有突破标记的空格。
- 只有当己方单位据守该格，或该格是仅以固有防御力防守的己方自由城市时，才能向其增援。
- **华约**单位永远不能从敌控格中反应。
- **北约**单位只有在所离开的格中仍留有另一个北约机动单位时，才能从敌控格中反应。北约单位只能反应进入格中单位全部与其国籍相同的格子。

每次进攻有防守方的格子后，防守方都会被询问，并看到每个不能反应的相邻单位受阻的原因。防守方也可以放弃反应，以格中原有单位迎战；没有任何单位能够反应时，直接继续进行战斗。由于已经防守过的单位不能反应，进攻方安排战斗的顺序很重要。

## 战斗比

进攻方战力相加（保留小数）后向下取整。每个进攻单位的攻击力：

- 混乱时减半；
- 缺乏战斗补给时减半；
- 装甲单位攻击城市或山地格时减半；
- 跨越小河格边时减少四分之一，跨越大河格边时减半。

防守方战力相加后向上取整（至少为 1）。每个防守单位的防御力：

- 混乱时减半；
- 缺乏战斗补给时减半；
- 软目标单位位于森林、崎岖地、山地或城市格时加倍；北约软目标单位位于筑垒格时也加倍（见[战役剧本](campaigns.md)）。

敌方自由城市加上其固有防御力。炮兵师像机动单位一样以完整防御力防守。只有当格中没有机动单位防守时，HQ 才加上其防御力。处于铁路标记下的单位，以及本阶段已从先前战斗中撤退的单位，不提供防御力。

以攻击力除以防御力，按有利于防守方的方式取整，得到 1:4 到 10:1 的战斗比栏。然后移栏：

| 条件 | 移栏 |
| --- | ---: |
| 目标格为大型或关键城市 | −2 |
| 目标格为森林、崎岖地、山地或小城市 | −1 |
| 华约进攻筑垒格（取代地形移栏） | −2 |
| 侧翼攻击：所有相邻格都有进攻方单位或处于其控制区，且防守方与另一个己方单位或自由城市相邻 | +1 |
| 包围攻击：如上被包围，且没有这样的相邻友军 | +2 |
| 北约遭奇袭的回合，华约的进攻 | +1 |
| HQ 提供的进攻支援 | +1 |

净移栏最多向任一方向移动两栏；但在奇袭回合，华约进攻的向上移栏不受限制。

## 战斗结果表

在最终栏掷一个骰子。结果格式为*进攻方/防守方*：

- **A1：**进攻方损失一个战力面。
- **\*：**该方单位陷入混乱。
- **CA：**防守方每个未混乱且有补给的机动单位战力面进行一次反击：掷一个骰子，目标为最强的进攻单位；西德 3+、其他北约或苏军 4+、其他华约 5+ 时使目标混乱。北约只能以一个国籍反击：合格战力面最多的那个国籍。
- **D#：**防守方损失相应数量的战力面：先由机动单位和炮兵师承受，从最强的开始；HQ 改为被压制；单独防守的铁路标记单位被消灭。
- **R#：**防守方撤退相应格数。

结果按以下顺序执行：反击、防守方损失、撤退、防守方混乱、进攻方损失、进攻方混乱。若防守方无法承受其全部损失，进攻方忽略 A1。

## 撤退

崎岖地、小城市或由北约防守的筑垒格使撤退减少一格；山地或大型、关键城市使撤退减少两格。

防守单位一起撤退，最终须距目标格相应格数。不能进入有敌方单位的格子、敌方控制的城市或禁行地形。在合法路线中，依次优先选择：

1. 战力面损失最少；
2. 终点不与敌方单位相邻；
3. 不超出堆叠上限；
4. 避开山地和大河格边；
5. 终点尽量远离进攻方。

单位每进入一个没有己方单位或自由城市的敌控格，就损失一个战力面；每有一格无法撤退，也损失一个战力面。若第一格有己方单位、能减少撤退的地形或（对北约而言）筑垒格，可以停在该格。必须撤退的铁路标记单位被消灭。

存活的防守单位本阶段不能再次防守。

## 推进

当目标格内没有防守单位时，进攻方可以让存活的进攻单位推进进入目标格（受堆叠上限限制），也可以选择不推进。然后在该格放置突破标记。

- 单独防守的敌方**自由城市**只有在战斗造成战力面损失时才失去其固有防御力；否则进攻方不能推进。
- 推进进入敌方城市即取得其控制权。
- 若因无人推进而敌方自由城市仍守住该格，则不放置突破标记。

攻击只有突破标记的空格不需要掷骰：投入的单位直接推进即可。
