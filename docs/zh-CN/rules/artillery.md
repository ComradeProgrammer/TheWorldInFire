# 炮兵

炮兵师是只通过**炮兵打击**作战的战斗单位。它们从不发动地面进攻，但当敌方进攻其所在格时，会像其他战斗单位一样参与防守。

## 开火

在己方的进攻打击阶段，行动方可以让每个炮兵师各开火一次，顺序任意，然后再结束阶段。炮兵师独立开火：所在格内不需要有其他己方单位。

开火时选择：

- 一个与炮兵师相邻且有敌方单位的**目标格**。炮兵不能跨越阻断格边、全海格边或丹麦渡轮开火；河流等其他格边不会削弱其火力；
- 该格中最多**两个敌方战力面**。第一个指定的单位承受战力面损失。HQ 必须单独作为目标。

以下炮兵师不能开火：

- 本回合已经开过火；
- 缺乏战斗补给；
- 处于铁路标记下；
- 不在地图上。

## 结算

炮兵打击与战斗轰炸机的地面打击一样在打击表上结算（见[空中力量](air-power.md)）。掷 d6，并加上目标修正：

| 条件 | 修正 |
| --- | ---: |
| 目标位于大型或关键城市 | −2 |
| 目标位于森林、崎岖地、山地或小城市格 | −1 |
| 华约打击筑垒格内的北约单位（取代地形修正，见[战役剧本](campaigns.md)） | −2 |
| 目标处于铁路标记下（取代地形修正） | +1 |
| 北约遭受奇袭的回合，华约的打击 | +1 |

空域不修正炮兵打击；该修正只适用于空中打击。各目标的修正不同时，取最低的总和。

炮兵师在 **“1”** 栏开火。被压制的炮兵师仍可开火，但使用 **“0”** 栏：

| 修正后点数 | “0”栏 | “1”栏 |
| --- | --- | --- |
| 1 或以下 | 无效果 | 无效果 |
| 2–3 | 无效果 | 所有目标陷入混乱 |
| 4 | 所有目标陷入混乱 | 所有目标陷入混乱 |
| 5 | 所有目标陷入混乱 | 第一个目标损失一个战力面，其余混乱 |
| 6 或以上 | 第一个目标损失一个战力面，其余混乱 | 第一个目标损失一个战力面，其余混乱 |

若打击消灭了该格最后一个敌方单位，在该格放置突破标记。

## 压制

炮兵师本应陷入混乱时（无论来自敌方打击还是战斗），改为被**压制**。被压制的炮兵师在“0”栏开火，防御力减半，并且只能以最小移动移动一格。压制标记在所属方的战后阶段移除。

## 防守

炮兵师从不进攻、从不反击，也从不被投入战斗。其所在格遭到进攻时，无论格内是否还有其他单位，它都像机动单位一样加上完整的防御力。混乱/压制和缺乏战斗补给的减半照常适用。承受战力面损失时，它与机动单位按同一顺序处理，从最强的开始。
