# 回合流程

游戏回合数由剧本决定。规则原型场景最多进行十四个完整回合，BALTAP 1983 进行七个完整回合。

每个回合依次由联合玩家回合、华约玩家回合和北约玩家回合组成。

## 联合玩家回合

双方依次完成：

1. 联合状态阶段
2. 联合增援阶段

联合增援阶段自动完成，不需要玩家输入。双方获得本回合的空中点数，预定的增援到达。

联合玩家回合结束后，华约开始行动。

## 玩家回合

每个玩家回合依次经历以下阶段：

1. 战前阶段
2. 战斗计划阶段
3. 进攻打击阶段
4. 战斗阶段
5. 预备队阶段
6. 战后阶段

阶段必须按照以上顺序完成。当前阶段结束后才能进入下一阶段；已经结束的阶段不能在同一玩家回合内重新进行。

战前阶段自动完成，不需要玩家输入。进入战前阶段时，游戏记录当前行动方各单位适用的 HQ 补给、移动补给和战斗补给状态。新到达的增援和位于战略预备队的单位具有补给。结算完成后，游戏自动进入战斗计划阶段。

战斗计划阶段合并原移动、恢复和战斗计划中的玩家操作。行动方可以按任意顺序选择一次再补给的对象、移动单位、命令单位装车或下车、使用铁路或空运，以及设置或取消攻击目标。移动遵循[移动规则](movement.md)。攻击目标必须是当前至少有一个敌方单位的格子，或是敌方自由城市（见[城市](cities.md)）。海运尚未纳入当前实现。装车需要一个完整的己方计划阶段；单位在下一次己方计划阶段开始时成为已装车状态，之后才能进行铁路移动。

在战斗计划阶段结束前，该阶段下达的任何命令都可以收回：取消再补给选择、移除攻击目标、撤销单位最近一次移动、取消装车命令，或恢复本阶段下车单位的已装车状态。单位在下车后进行过非铁路移动，或恢复后会超出该方铁路运力时，不能撤销下车。

战斗计划阶段结束时，移除行动方的混乱标记。

在进攻打击阶段，行动方下达并结算空中任务：对敌方单位的空中打击和空中遮断区（见[空中力量](air-power.md)）。随后是战斗阶段；地面战斗尚未纳入当前实现。

预备阶段结束时，移除行动方的突破标记和敌方的空中遮断区。战后阶段自动完成，并移除行动方的压制标记。

华约完成整个玩家回合后，北约开始行动。北约完成整个玩家回合后，本回合结束，进入下一回合的联合状态阶段。

剧本最后一个回合中，北约完成战后阶段后，游戏结束。
