# 回合流程

一局游戏最多进行十四个完整回合。

每个回合依次由联合玩家回合、华约玩家回合和北约玩家回合组成。

## 联合玩家回合

双方依次完成：

1. 联合状态阶段
2. 联合增援阶段

联合玩家回合结束后，华约开始行动。

## 玩家回合

每个玩家回合依次经历以下阶段：

1. 战前阶段
2. 战斗计划阶段
3. 进攻打击阶段
4. 战斗阶段
5. 预备队阶段
6. 战后阶段

阶段必须按照以上顺序完成。当前阶段结束后才能进入下一阶段；已经结束的阶段不能在同一玩家回合内重新进行。

华约完成整个玩家回合后，北约开始行动。北约完成整个玩家回合后，本回合结束，进入下一回合的联合状态阶段。

第十四回合中，北约完成战后阶段后，游戏结束。
