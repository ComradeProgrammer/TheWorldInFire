# 空中力量

空军以有名称的中队级算子表示。每个算子有完整和削弱两个战力面，并驻扎在地图外机场。当前系统有三种空军单位：

- **战斗机**执行制空任务，在指定格周围的战斗半径内与敌方战斗机交战，并截击敌方战斗轰炸机。
- **战斗轰炸机**打击地图上的地面单位或敌方地图外机场。
- **预警机（AEW）**在指定格周围的支援半径内为本方空战提供修正。当前版本不能攻击预警机。

飞机受损时翻到削弱面；再损失一个战力面时被消灭。中止任务的飞机本回合不能继续执行任务。每个新回合的联合增援阶段，仍然存活的飞机恢复为可出动状态；已经损失的战力面不会自动恢复。

## 地图外机场

每架飞机固定隶属于一个地图外机场。机场有地图边缘的锚点格和每回合出动容量。锚点用于显示航线和判断截击；当前版本不限制机场到目标的航程。

机场可以成为空袭目标：

- 0 点损伤：使用完整出动容量；
- 1 点损伤：容量减半，向上取整；
- 2 点损伤：机场关闭，不能出动；
- 被压制：在压制持续期间不能出动。

机场损伤不会影响本回合已经起飞的飞机，第一版也不会自动修复。

## 战斗计划阶段

玩家在自己的战斗计划阶段给每架可用飞机指定至多一个任务。任务在阶段结束前可以撤回。

| 飞机 | 可选任务 | 需要指定 |
| --- | --- | --- |
| 战斗机 | 制空 | 战斗空域中心格 |
| 战斗轰炸机 | 地面打击 | 目标格及该格内至多两个战力面 |
| 战斗轰炸机 | 机场打击 | 一个敌方地图外机场 |
| 预警机 | 空中预警 | 支援中心格 |

同一架飞机每回合只能执行一次任务，所有任务还受所属机场的有效出动容量限制。地面打击不能重复指定同一个单位；HQ 必须单独成为目标。

## 联合空中行动阶段

双方都完成战斗计划后，游戏自动进行联合空中行动。所有掷骰和修正都会写入事件记录和空中行动报告。

### 战斗机对战斗机

战斗机以任务中心格为圆心，在当前战力面的战斗半径内投射战斗空域。当两架敌对战斗机的空域相交时，它们可能配对交战。游戏采用确定性的最大配对，使尽可能多的敌机同时交战；每架飞机在一轮中只参加一次交战。

每对战斗机同时攻击。攻击方以自己的空战值减去目标的规避值，得到空战表列（限制在 −4 至 +4），掷 d20，再加上有效预警机修正后查空战表。双方结果同时生效。仍可作战且空域仍相交的飞机会进入下一轮，直到没有可配对的敌机。

预警机在其支援半径内提供印在当前战力面上的修正；多个预警机的修正不累加，只取最高值。

### 战斗机截击战斗轰炸机

制空战结束后，仍可作战的战斗机检查敌方战斗轰炸机的目标格。目标位于战斗机战斗半径内时可以截击。每架战斗机最多截击一架战斗轰炸机，每架战斗轰炸机最多被一架战斗机截击。

截击仍使用同一张空战表，双方同时攻击，所以战斗轰炸机也会还击。被中止或消灭的战斗轰炸机不会执行原定打击；只损失一个战力面但没有被消灭时，也按空战结果中止本次任务。

## 进攻打击阶段

联合空中行动后，幸存且未中止的战斗轰炸机在所属方的进攻打击阶段开始时自动执行计划中的任务。该阶段保留为可停留的检查点，玩家可以查看结果，然后结束阶段。

### 地面打击

地面打击沿用 NATO 空袭规则。每架战斗轰炸机掷 d6，加上飞机当前战力面的打击修正和目标修正：

| 条件 | 修正 |
| --- | ---: |
| 目标位于大型或关键城市 | −2 |
| 目标位于森林、崎岖地、山地或小城市格 | −1 |
| 目标处于铁路标记下（取代地形修正） | +1 |
| 目标格位于打击方的己方空域 | +1 |
| 目标格位于打击方的敌方空域 | −1 |
| 北约遭受奇袭的回合，华约的打击 | +1 |

| 修正后点数 | 结果 |
| --- | --- |
| 1 或以下 | 无效果 |
| 2–4 | 所有目标陷入混乱 |
| 5 或以上 | 第一个目标损失一个战力面，其余目标陷入混乱 |

若任务指定的目标在结算前已经全部消失，任务记为目标消失，不改选新目标。

### 机场打击

机场打击也掷 d6，并加上飞机的打击修正和机场自身修正：

| 修正后点数 | 结果 |
| --- | --- |
| 1 或以下 | 无效果 |
| 2–4 | 机场压制到下一回合结束 |
| 5 或以上 | 机场增加 1 点永久损伤，并压制到下一回合结束 |

## 地面空域

原有的静态空域规则继续用于地面移动、铁路移动和空运。它由有补给的地面单位及受控城市投射，与战斗机的战斗空域是两个独立概念。战斗机空域只用于空战和截击，不会追溯改变本回合已经完成的地面移动。
