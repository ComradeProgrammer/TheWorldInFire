# 空中力量与进攻打击阶段

## 空域

每个格子对某一方而言都是己方空域、争夺空域或敌方空域，判断总是站在其中一方的角度。

- 一方在其每个有补给的单位、以及其控制的每个城市**五格以内**投射空域。战略预备队中的单位不计入。西柏林永不投射空域。
- 只有己方投射到的格子是**己方空域**；只有敌方投射到的格子是**敌方空域**；双方都投射到（或双方都未投射到）的格子是**争夺空域**。

空域影响移动：

- 行军移动和铁路移动必须从己方空域出发，并全程留在己方空域内。
- 单位只能在己方空域内装车。
- 空运不能从敌方空域出发，也不能降落在敌方空域。

## 空中点数

每个游戏回合开始时，在联合增援阶段，双方获得剧本规定的空中点数。回合结束时未使用的点数作废。

- **战术空中点数**只能用于己方或争夺空域。
- **战役空中点数**可用于任何地方；只有战役空中点数可以打击 HQ。
- 部分剧本给予一次性的额外战术空中点数，可在任意一个回合使用。当回合的战术空中点数用完后，会自动使用它。

## 进攻打击阶段

在进攻打击阶段，行动方花费空中点数执行**空中任务**。先下达所有想执行的任务，然后一并结算。结算前，任何任务都可以撤回并返还点数；结算后，本阶段不能再下达新任务。结束阶段时，会自动结算尚未结算的任务。

### 空中打击

每个空中点数对一个格子中的敌方单位进行一次空中打击：

- 一次打击最多针对两个战力面：两个单战力面单位，或一个双战力面单位。
- HQ 只能被单独打击，且只能使用战役空中点数。
- 同一阶段内，任何单位不能被打击两次；一个格子最多承受两次空中打击。
- 打击指定两个单位时，由第一个指定的单位承受战力面损失。

结算时掷一个骰子，加上修正值后查表：

| 修正后点数 | 结果 |
| --- | --- |
| 1 或以下 | 无效果 |
| 2–4 | 所有目标陷入混乱 |
| 5 或以上 | 损失一个战力面，其余目标陷入混乱 |

骰子修正：

| 条件 | 修正 |
| --- | ---: |
| 目标位于大型或关键城市 | −2 |
| 目标位于森林、崎岖地、山地或小城市格 | −1 |
| 目标处于铁路标记下（取代任何地形修正） | +1 |
| 目标格位于打击方的己方空域 | +1 |
| 目标格位于打击方的敌方空域 | −1 |
| 北约遭受奇袭的回合，华约的打击 | +1 |

若各目标适用的修正不同，本次打击采用较低的修正总和。

**战力面损失：**双战力面单位翻到削弱面并陷入混乱；单战力面单位被消灭。HQ 永远不会被削弱：对 HQ 的任何结果都改为使其被压制。

**突破：**若打击消灭了一个格子中最后的敌方单位，在该格放置突破标记。突破标记在打击方的预备阶段结束时移除。

### 空中遮断

空中点数也可以不用于打击，而是在一个陆地格放置**空中遮断区**：被标记的格子及其周围六格。战术空中点数只能放置在己方或争夺空域。遮断区只影响另一方的单位：

- 战术移动进入遮断区内的格子额外消耗 1 移动点（离开不额外消耗）。
- 行军移动和铁路移动不能进入遮断区。

遮断区在任务结算时生效，并在敌方下一个预备阶段结束时移除。

## 混乱与压制

**混乱**的单位：

- 只能以最低移动移动一格（不能行军、铁路移动或空运）；
- 不能装车，并立即失去任何铁路标记。

混乱标记在该单位所属方结束战斗计划阶段时（即完成移动之后）移除。

HQ 不会混乱，而是被**压制**。被压制的 HQ 受到同样的限制；压制标记在其所属方的战后阶段移除。
