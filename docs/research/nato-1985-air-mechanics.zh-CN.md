# NATO 与 1985：空中机制详细说明与对照

整理日期：2026-10-03。本文总结两款桌游的原版规则，作为规则研究资料；不表示 OOAW 已经实现这些机制。

本文先介绍航空资源和行动规则，再说明它们与地面战、补给、基地及剧本的关系，最后通过逐步示例解释一回合内如何使用。示例中人为设定的部队性能、航空点收入和查表结果均明确标作假设，不代替正式算子或玩家图表。

## 2. 核心区别

**NATO 从地面指挥官的角度处理航空兵：玩家分配已经突破敌方空战与防空体系的打击能力。1985 则要求玩家组织航空战役：先争夺制空权，再安排具体中队执行任务，处理护航、截击、防空、损伤与基地保障。**

| 项目 | NATO | 1985 |
| --- | --- | --- |
| 地图与时间尺度 | 每标准格 15 英里（约 24 km），每回合一天 | 每标准格 14 km，每回合两天；固定翼主要按 61 格组成的 Megahex 活动 |
| 固定翼航空兵 | 战术、战役航空点数 | 独立飞机中队，通常两步战力 |
| 制空权 | 有补给的地面单位、城市投射 5 格空域影响 | 在 Megahex 中分配中队，通过空战取得本回合制空权 |
| 空战 | 抽象在航空点数和运输拦截表中 | 攻击值、规避值、飞行员、数量优势、AEW、ECM 共同结算 |
| 出动频率 | 消耗本回合航空点数 | 普通中队每回合一次任务；制空区中队可多次截击、护航 |
| 对地任务 | 空袭、区域阻滞、北约纵深补给阻断 | 近距支援、地面打击、SEAD、Wild Weasel、补给阻断等 |
| 固定翼航程 | 航空点数按空域限制使用；运输基本无距离上限 | 按任务、国籍和飞行路径计算作战半径；延伸航程降低攻击能力 |
| 防空 | 固定翼防空已抽象；直升机逐格受 Flak 攻击 | SAM、机动 ADA、部队自带防空、基地固有防空、舰载防空 |
| 空运 | Ferry 与 Airlift Command；每个 Command 每回合运一步 | 运输中队运力、运输成本，以及独立战略空运点数 |
| 直升机 | 运输 Command 和攻击直升机旅；按格、航段移动 | 独立中队，基地、往返总移动力、超低空飞行、运输和支援 |
| 机场 | 无逐座机场保障体系；核化攻击抽象削减航空点数 | 机场驻扎、保障容量、修理容量、损坏、占领、启用 |
| 航空技术差异 | 1988 航空战役掷骰 +1；美军攻击直升机更耐打 | 中队性能、飞行员、长航程、隐身、ECM、AEW 等 |
| 天气 | 本规则体系没有独立天气航空模块 | 可选坏天气规则限制任务和空降 |

这里的 NATO 指游戏名；1985 规则中的 NATO 指北约阵营。两者的规则不能因术语相同而直接互换。

距离与出动次数也必须连同尺度理解：两款游戏中的“5 格”“每回合一次”并不表示相同的实际距离或时间。尺度来源：NATO §2.7，p.9；1985 §3.1、3.3，p.4。

## 3. NATO：空域与航空资源

### 3.1 空域控制

每个六角格相对一方具有友方、争夺或敌方空域状态。判断依据是：该格是否位于本方或敌方**当前能追溯移动补给的单位**、**有补给的己方控制城市**的 5 格内。

| 本方覆盖 | 敌方覆盖 | 相对本方的空域 |
| --- | --- | --- |
| 有 | 无 | 友方 |
| 有 | 有 | 争夺 |
| 无 | 有 | 敌方 |

规则没有为双方都无覆盖单独定义第四种空域；规则的地图设计说明依赖城市覆盖后方。不要自行从这个表推导一个“中立空域”规则。

空域在需要时按实际态势判断，不能只看单位已有的缺补给标记。为判断空域而临时检查补给，并不改变该单位正式的移动补给状态。空海移动段中新到达的乘客部队，要等该段结束才开始影响空域，不能用第一次空降的结果立即改善同段后续运输的风险。

特殊情况：

- 友方战略预备区 SRB、增援区始终是友方空域；战前己方领土按友方空域处理。
- 驻东德的华约单位不投射对丹麦空域的影响；东德城市仍可投射。单位要在西德或丹麦才能从地面争夺丹麦空域。
- 西柏林及其初始北约守军不投射空域影响，通常处于华约友方空域。
- 依靠波罗的海军 HQ 海上补给的华约部队不投射空域影响；通过空中再补给标记获得补给的部队也不投射。
- 华约自动补给结束后，单纯因未支付 HQ 补给点而缺补给、其余补给路径条件都满足的单位，仍可用于判断空域。

来源：§11，pp.42–44；§10.7.3、10.8.3、10.9.3，pp.39–40；§16.4，p.52。

### 3.2 空域对行动的影响

March、Rail、Ferry 必须在友方空域中使用，包括相关起点与路径。进入争夺、敌方空域通常需要战术移动、最低移动、直升机移动或特殊运输行动。

战术航空点只能打击友方、争夺空域内的目标；战役航空点可以打击地图任意位置。普通空袭在友方空域掷骰 +1，在敌方空域 -1，争夺空域无此修正。这些修正适用于常规部队及 Reforger 空袭，不适用于核化攻击。

西柏林通常没有北约防御空袭支援，因为可执行该任务的只有战术航空点；外部有补给的北约单位靠近后才可能改变这一点。华约对西柏林的常规空袭通常得到友方空域 +1。

来源：§11.7–11.8，p.44；§23.4，p.66。

### 3.3 航空点数的产生与使用

一般剧本在每回合联合增援阶段，由华约在对应 **Air Campaign Table** 按回合列掷一次骰，同时决定双方的战术、战役航空点数。1988 版掷骰 +1。War of Nerves 有独立处理，见第 7 节。

| 资源 | 可执行的任务 | 关键限制 |
| --- | --- | --- |
| Tactical Air Point，战术航空点 | 常规空袭、区域空中阻滞；北约还可执行防御空袭、投送战术化学武器 | 常规目标和阻滞标记须位于友方或争夺空域；不能打击 HQ |
| Operational Air Point，战役航空点 | 任意空域常规空袭、HQ 空袭、区域阻滞；北约还可纵深阻断华约补给 | 不能用于北约防御空袭 |

两种点数在常规空袭表上的打击效果相同，差别是距离抽象、任务资格和使用时机。未使用的点数在本回合结束时丢失，不积累。核战争导致永久削减时，每回合战术航空点的收入最低为 2；BALTAP 的特殊低点数配额是另一个剧本规则。

来源：§23.1，pp.64–65。

## 4. NATO：打击与阻滞

### 4.1 常规空袭

每消耗 1 航空点，在一个目标格中打击最多两步目标：一个两步单位，或最多两个一步单位。每格每个打击段最多消耗 2 点，但必须分为两次独立空袭，各打击不同单位、各自掷骰；不能把两点叠加为对同一单位的一次更强攻击。一个单位在同一空袭段不能重复被空袭。

目标类型是战斗单位、HQ、Reforger 场址，三种不能混在一次空袭中。不能空袭无人驻守城市的固有防御力。地形、空域、列车状态、突袭等修正累加；列车上的单位、Reforger 场址不获得所在格的地形保护。打击两个具有不同修正的一步单位时，应依 §23.3.1 选择单打更易受损目标，或按较差条件打击两者。

| 结果 | 效果 |
| --- | --- |
| `*` | 目标混乱 Disrupted；HQ、炮兵改为压制 Suppressed |
| `D1` | 损失一步，其余被指定目标混乱；攻击方选择两支一步单位中谁被消灭 |
| HQ 上的 `*` 或 `D1` | 都只压制 HQ；必须用战役航空点，且 HQ 为唯一目标 |
| Reforger 上的 `*` | 场址受损；已有受损标记时再中一次则消灭；受损场址激活后，受损转为部队混乱 |
| Reforger 上的 `D1` | 消灭场址；美军 3ACR 的两步场址按专门规则逐步损失 |

HQ 被压制后仍能供给所属单位、调派攻击直升机，但不能提供进攻支援。空袭消灭一格最后的敌军时，可触发突破标记。对普通战斗单位，重复混乱不会自行转为战力损失；Reforger 的重复受损是特殊例外。

混乱本身就有明显战术作用：单位攻击、防御减半，不能反应、反击、上列车或进入预备，只能作最低移动，推进只能 Consolidate，不能 Exploit。空袭因此既用于造成战损，也用于削弱后续战斗、限制敌人机动。HQ、炮兵的压制还受自身特殊效果与不同移除时点控制。

来源：§23.1.5–23.1.6、23.3–23.6，pp.64–67；§25.6.4，p.78；§33.3.3–33.3.5，pp.98–99。

### 4.2 时机、计划与双方不对称

双方都可在自己进攻打击阶段执行空袭。所有目标格及投入点数必须先标记完，再开始结算；具体选择格内哪个单位，可以等该次空袭执行时公布。

北约还可在华约每次地面战斗的防御打击段，投入最多 2 战术航空点，打击参与**当前这场攻击**的华约地面单位。两点可分配到两个格或同一格不同单位。未参与攻击的同格单位、提供支援的 HQ、此前实施炮击的炮兵师都不能借此被打击。两次空袭也须先一并声明，然后结算。无北约地面单位的自由城市被攻击时，仍可按空域条件呼叫北约空袭。

华约没有对应的防御空袭能力。北约因此需要在防御即时使用和自己回合进攻之间分配同一个点数池。

空袭可以打击空降、机降突击目标格内的敌军，即使同格有己方突击部队；核化攻击不能这样打击己方突击目标格。

来源：§20，p.59；§23.2，p.65；§27.2–27.3.3，p.88。

### 4.3 两种阻滞

| 任务 | 消耗与覆盖 | 效果与持续时间 |
| --- | --- | --- |
| Air Interdiction Zone，区域空中阻滞 | 双方均可用 1 任意类型航空点，建立中心格及相邻 6 格的区域；战术点仍受空域限制 | 敌军战术移动进入每格额外 +1 MP；禁止敌军 March、Rail 进入；敌方标记在己方预备阶段结束移除 |
| NATO Deep Interdiction，北约纵深阻断 | 每个北约回合最多一次，用 1–3 战役航空点掷专用表 | 减少华约**下回合新收到的**补给点；不扣现有库存，最低收入 0，未吸收损失不结转 |

区域阻滞不是 ZOC，不切断补给线，不影响空海、直升机移动，也不影响反应、撤退、推进。纵深阻断没有华约对北约的对称版本，因为游戏的双方补给模型不同。

来源：§23.7–23.8，p.67。

## 5. NATO：空运、空降、空中补给

### 5.1 Ferry 与军事运输

**Air Ferry 是友方后方运输；Air Transport 使用有限的军事空运 Command，可以在争夺空域运送部队。Paradrop 是允许进入敌方空域的特殊 Air Transport。**

| 行动 | 运力 | 起止与路径 | 风险、落地后行为 |
| --- | --- | --- | --- |
| Air Ferry | 不消耗 Airlift Command；总次数不受军事运力池限制 | 有 `A` 移动力标识的空降、空中机动单位；友方空域的城市到己方控制城市；也可从 SRB、增援区进入地图；全路径友方空域，不能经过敌军或 EZOC | 按剧本/回合的 Ferry 拦截表；成功到达后不能在该移动阶段再移动 |
| Air Transport | 每个 Airlift Command 每回合运输一步 | 同样要求 `A` 单位；城市/SRB/增援区出发；普通运输起止需有移动补给、不在 EZOC、不在山地或核化污染格；路径不能进入敌方空域；目的地不一定是城市 | 运输拦截；成功到达后 Command 进入 Recovery，部队本移动阶段不能再移动 |
| Paradrop | 使用 Airlift Command | 必须有空降兵符号；目的地为 Clear 或 Marsh；可进入敌方空域、EZOC、敌军占据格；目的地无需可追溯移动补给 | 拦截时目的地 EZOC 增加危险；落地后可攻击邻格敌军；直接落到敌军格触发 Assault |

Ferry、Transport 乘客均不能带列车标记，不能处于混乱或压制状态；核化污染限制起止。Transport 的中途路径可以飞越敌军、EZOC、禁行地形与污染格，不能把起止限制误用于整条航路。Ferry 的路径限制更严。

所有 Lift Command 平时位于 Ready，使用后进入 Recovery，在下回合联合状态阶段恢复；被消灭则永久失去。相互距离在 2 格内的多个运输/机降目的地，必须在执行前一并计划，不能看第一次是否成功再临时追加替代行动。

来源：§14.1，p.49；§15，p.50；§16.1、16.3–16.4，pp.50–52。

### 5.2 运输拦截

本游戏的 **Interception 是运输损失检定**，不是逐架战斗机交战。空运、海运及相应增援都会受到影响；它也抽象了对海运的潜艇攻击。

1. 使用移动方阵营的 Interception Table，按剧本、当前回合、行动类别及经过的危险空域确定阈值。
2. 每个被运输的战力步，在到达目的格时检定一次，与移动距离无关。
3. 掷 2d6；起点或终点在 EZOC 中则结果 -1，友军不能消除该拦截修正。
4. 修正后结果不大于阈值，表示截获成功：乘客步被永久消灭；使用军事运输 Command 时，它也一起永久消灭。
5. 表项为 `NA` 时免检。两步单位分别检定；HQ 的消灭与重建遵循 HQ 特例。

Ferry 全程友方空域，使用对应友方空域部分；普通 Transport 通常使用争夺空域部分；空降/两栖行动只要路径有一格进入敌方空域，就使用敌方空域部分。损失 Ferry 乘客不会削减以后无限 Ferry 的能力；损失 Lift Command 会削减以后军事运输能力。

来源：§17，pp.53–54。

### 5.3 空中再补给

每个己方移动补给段，正常补给检查后，可以对地图上一个有己方战斗单位的格执行一次 Resupply Operation。它使用**假定的空运 Command 与补给点**，不消耗实际军事运力或实际补给点，可进入任意空域，但必须通过运输拦截。

成功后补给同格所有战斗单位，立即移除移动缺补给；随后恢复阶段可移除同格战斗缺补给，或保留标记供本回合后续战斗使用。标记最晚在该方本回合战斗阶段结束消失。不能补给 HQ、城市或邻格，也不能借此投射空域控制。

空降部队到达时具有战斗补给；打过一场战斗后，若无法在战斗补给检查时追溯补给，才变为战斗缺补给。

来源：§10.6.3、10.7，pp.38–39。

### 5.4 空运增援、Reforger 与跨大西洋风险

- 空中增援先进入 SRB，再以 Air Ferry、Air Transport 进入地图；正常运输拦截仍适用。可延迟并改走铁路。
- 直升机不能从 SRB 直接进入地图；可从增援区进入。
- Reforger 把人员飞到预先储存装备的场址，每个到达的 Reforger Step 激活相应场址；这类到达**不受运输拦截**，代表人员可在安全后方落地后转运。场址本身可被华约空袭。
- 美、加的**海运**增援进入 SRB 前，需额外做 CONUS 跨大西洋拦截，War of Nerves 和平回合除外。其主要代表苏联潜艇威胁，不是另一种空降规则；无论实际剧本，使用固定指定的 Strategic Surprise 友方 Ferry 列。离开 SRB 进入地图时还可能再做正常拦截。
- Extended Buildup 已完成 Reforger，因而没有未激活场址的逐回合到达。可选美军 101st 与 XVIII HQ 增援还带来 1 Helicopter Command；XVIII HQ 首次入图可空运，是 HQ 的专门例外，进入后不能再次空运。

来源：§18.1.8，p.55；§33.2–33.3，pp.97–99；Play Booklet §38.4.3.5，p.14。

## 6. NATO：直升机与防空

### 6.1 直升机运输

运输直升机必须使用 Helicopter Command，无不消耗 Command 的 Helicopter Ferry。只运有 `A` 标识的空降、空中机动单位。

| 行动 | 去程 | 返程 |
| --- | --- | --- |
| Insertion，投送 | 搭载乘客，最多 10 格，到目的地卸载 | 空机返回；若目的地已满足安全回收条件，可直接回收，无需实际返航 |
| Extraction，撤出 | 从己方安全一侧空机出发，最多 10 格，接到乘客 | 搭载乘客返回，最多 10 格 |

每一航段独立计算 10 格，忽略飞越地形，可越过海面、敌军和 EZOC；不能在全海格或敌控城市结束。回收位置必须是陆地、无未被其他友军或己方自由城市抵消的 EZOC，并能以不超过 10 格的补给线连接一个有补给的己方城市。

投送乘客须有移动补给、未混乱、无列车标记、不在核化污染格，起点无未被其他友军抵消的 EZOC。撤出乘客的资格更宽，仅要求无列车标记且不在核化污染格，因而可以营救混乱、缺补给部队。去程起点不能在未被抵消的 EZOC。运输段投送的部队可在随后战斗阶段攻击。

预备阶段也能机降，但乘客须有 Reserve/OMG 标记，只能投送，每段最多 5 格，不能直接落入敌军格发动 Assault。该机降可与预备战术移动按任意顺序组合。

来源：§18.1–18.3，pp.54–56；§28.2.2，p.90。

### 6.2 攻击直升机旅

攻击直升机附属特定美军军级 HQ 或华约方面军 HQ，不能调换隶属关系。任务必须涉及所属 HQ 的至少一个下属单位或 HQ 自身，但该参战单位无需位于 HQ 的支援范围内。

- 进攻：从 Ready 放在所属 HQ 上，最多飞 5 格进入目标格。
- 北约防御：目标格有美军单位时可调派符合隶属条件的美军攻击直升机，最多飞 5 格进入一个参战进攻敌军所在格。华约没有对称的防御任务。
- 存活抵达后使战斗比获得己方有利的 1 列移动；双方均投入时互相抵消。仍受战斗总净列移上限等通用规则约束。
- 战斗后最多飞 5 格回所属 HQ，再进入 Recovery；每回合只恢复一次。因此北约防御时用过，就不能在本回合再用于自己进攻。
- HQ 被压制仍可调派，HQ 缺补给不能调派；攻击直升机不能作为地面战斗步损来吸收损失。

来源：§18.4，p.56；§25.3.4.4，pp.75–76；§25.6.3.3，p.78。

### 6.3 Flak 结算与登陆区

NATO 的独立 Flak 机制针对 Helicopter Command 与攻击直升机；固定翼飞机的地面防空损失已经包含在航空点数/运输拦截抽象中，没有单独部署 SAM、ADA、SEAD 的流程。

直升机每次进入一个 EZOC 格，立即检定一次，包括敌军所在格；去程、返程都可能触发。

1. 掷 1d6，普通格结果 1 命中；敌方自由城市格结果 1–2 命中。
2. 命中后再掷 1d6；结果大于直升机的防御强度则击落并永久消灭。
3. 如果击落时带乘客，乘客一同消灭。投送去程进入卸载格时仍带乘客；成功卸载后的空机返程损失不再影响乘客。撤出空机去程损失不伤乘客，载人返程损失才伤乘客。

多个敌军 ZOC 叠加不增加检定；其他己方地面部队或己方自由城市可在其所在格抵消 EZOC，正在运输的乘客本身不算。

空 EZOC 格的热着陆区 Hot LZ：第一支部队成功落地后，可掩护后续部队在该格着陆免受这次 Flak；连续撤出时通常最后一架进入才失去其他友军掩护。直接突击敌军格则不同：突击部队在战斗结束前无 ZOC，也不抵消守军 ZOC，所以每个投送 Command 都要接受目标格 Flak。攻击直升机也依突击双方的 ZOC 特例处理。

美军攻击直升机防御强度：1983 为 2，1988 为 3。作为规则计算示例，一次普通 EZOC 入格的击落概率分别为 `(1/6)×(4/6)=1/9` 与 `(1/6)×(3/6)=1/12`；自由城市加倍。这只是单次 Flak 风险，多个入格检定会累积风险。

来源：§19，pp.56–57；§3.6，p.15。

### 6.4 空降、机降突击 Assault

空降或机降直接进入敌军占据格时触发 Assault，必须在同回合战斗阶段解决。不能突击城市格；进入目标格的己方机动部队最多 4 步，敌军不占己方堆叠容量。北约须同国籍，华约须能协调。

突击部队攻击力翻倍，可与邻格部队共同攻击；战损首先由突击部队承担。如果战后目标格仍有守军，格内全部突击部队消灭。突击部队在战斗完成前无 ZOC，不能保护后续机降，却可通过身在目标格的规定牵制守军反应。常规空袭可以支援同格突击，核化攻击禁止。

来源：§27，pp.88–89。

## 8. 1985：单位、航程与出动循环

### 8.1 航空兵的表示方法

飞机、直升机均为独立中队，通常两步；标准格约 14 km，61 个标准格组成一个 Megahex，固定翼航路和制空区以 Megahex 为主要尺度；每回合代表两天。使用 d20，未另作说明的分数向下取整。

中队的攻击/空战值、规避 Evasion、对地/对海 Strike、飞行员等级、运输容量及特殊能力分别参与对应结算。固定翼飞机不和直升机共用移动体系。

| 专门类型/代码 | 作用与限制 |
| --- | --- |
| R | 侦察机；不能制空、护航、截击 |
| B | 战斗轰炸机/轰炸机；不能制空、护航、截击 |
| N | 海军攻击机；不能制空、护航、截击、对地打击 |
| T | 运输机；不能制空、护航、截击、对地/对海攻击 |
| ECM | 支援任务、降低敌方空战/防空效率 |
| AEW | 预警与指挥；支援制空区、空战和截击 |
| Rn | 长航程；标准、延伸作战半径都翻倍 |
| W | 能完成 Wild Weasel 任务 |
| Sh | 隐身；须整个任务全部友方中队均隐身才得到隐身任务效果 |

来源：§3.1–3.4，p.4；§24.2、24.4、24.12、24.19、24.22，pp.22–29；§30.2，p.37。

### 8.2 回合与状态

每回合先重置资源，再处理天气、紧张局势、事件、WMD、SSM 化学攻击，随后进行制空区放置/海上监视放置/秘密分配/制空战，接着核打击、东方阵营行动、西方阵营行动，最后回合结束处理。

普通未驻制空区中队每回合只能执行一次任务，结束进入基地 Used；在任一方移动步，双方均可按任务时机出动。双方同时希望出动时，行动方优先。

留在制空区的中队可在本回合多次截击、护航，任务后返回原制空区；中止任务或全部剩余步损坏时可能退出。回合结束时制空中队回到有效基地 Used，移除制空及 Wild Weasel 标记，修理损坏飞机，恢复 Ready。直升机另按每个 Action Phase 一次任务处理。

来源：§4，p.5；§24 总则，p.22；§25.1，p.30。

### 8.3 航程与编组

每个中队分别计算到目标的 Flight Path，按任务和国籍查 Combat Radius Table。

- 不超过标准半径：使用印刷能力。
- 超过标准、但不超过两倍：使用延伸航程；Attack、Strike 各 -2，最低 1。
- 超过两倍：不能执行；Rn 先把两种半径都翻倍。
- 返回任一有效基地，目标到该基地须在本次使用的标准/延伸半径内，不必回原基地。

航路长度：起飞 Megahex 不计；每进入一个 Megahex +1；图外基地到指定入口按印刷 Entry Distance；图外基地与关联 LOC Box 之间 +1；每条 LOC Connection +5。基地转场 Ferry 无作战半径上限。

Air Group 由 1–3 个中队组成，可以混类型、国籍。遭受目标区防空时按组平均规避值处理，损失尽量平均，先从规避值最低者分配；航路/留空防空对单个中队结算，不用同一个组平均值。任务后组内中队可去不同基地。

来源：§24.4–24.6，p.23；§24.13，p.25。

## 9. 1985：制空战、护航与截击

### 9.1 制空权争夺

双方按剧本拥有一定数量制空标记，东方先放，交替选择尚无标记的 Megahex。放弃一次放置意味着放弃本阶段剩余标记，不能跳过等待。只能在作战地图放，LOC 地图不能取得制空区。

双方秘密向每个制空区分配最多 15 中队，并分配同一 Air Theatre 的 AEW；不论谁放的标记，双方都能争夺。双方都没投入中队的区域移除。

争夺流程：航路防空 → 留空防空 → 双方秘密在编号位置编组 → 比较未损坏步数的数量优势 → 同编号中队交战。各自用己方 Attack 减敌方 Evasion 决定空战表列，再掷 d20 加修正；双方射击、损失同时发生。中止或全损坏者撤到基地 Used。还有双方中队时重新编组再打一轮；仅一方剩下时获得制空权，幸存中队留在区内。

获胜方 AEW 留在区内，败方 AEW 本回合不可再用。后续轮次从编组开始，不能误把最初防空阶段重复为每轮一次。

来源：§24.8，pp.23–24。

### 9.2 空战修正

| 因素 | 掷骰修正 |
| --- | --- |
| 飞行员 | 攻击中队 Pilot Rating 减防御中队 Pilot Rating |
| AEW | 北约支援攻击 +2、支援防御 -2；其他 +1/-1，按 AEW 所在区域的适用条件 |
| 数量优势 | 本阶段未损坏步数达到敌方两倍：攻击 +2；敌方达到本方两倍：攻击 -2 |
| ECM | 北约支援攻击 +2、支援防御 -2；其他 +1/-1；ECM 本身不能参加制空任务 |
| 来自制空区 | 仅截击空战：攻击 +1、防御 -1 |

适用修正累加。制空战每轮重算数量优势，截击战则在护航交战和攻击突击机两个阶段分别计算。

来源：§24.7，p.23；§24.8.4，p.24；§24.20.1，pp.27–28。

### 9.3 制空区的作用

制空区可以提供更有利的截击、护航；强制检定进入区域的敌方直升机；阻止敌方 Wild Weasel、海上监视、ASW 监视；剥夺敌方空降/空中机动部队的 General Supply；提高敌水面舰艇被发现程度。它不等同于 NATO 游戏里从地面部队投射的 5 格空域带，也不禁止一切敌方飞机飞入。

来源：§24.8 总则，p.23；§25.4，p.30。

### 9.4 截击与护航的全过程

敌任务经过己方制空区时，可以用该区中队沿途截击；若任务的中队走不同路线，只能截击实际经过该区的中队。任务到达目标区域后，还能用有效基地中队及同 Megahex 制空区中队截击。普通任务上限通常 6 截击中队，地面支援为 10。

1. **能否截获**：基地起飞截击者每中队掷骰，按飞行距离、AEW 修正，达到 9 才成功；失败回有效基地 Ready。制空区中队自动成功，隐身任务除外。
2. **截击方也挨防空**：基地来机接受航路防空；制空区来机免此航路防空，但参与者仍接受目标区 On-Station 防空。
3. **秘密编组**：任务方把 Strike、Escort 中队放编号位置，截击方放 Intercept 中队；同时揭示。
4. **先过护航屏障**：截击中队选择 Engage，与护航交战但放弃攻击 Strike；或 Evade，接受护航火力却不回击，以争取攻击 Strike。同编号配对，未配对中队按规定可攻击其他目标。
5. **再攻击任务机**：成功 Evade 的幸存者进入 Attack 位置，攻击对应 Strike 中队。Strike 不在这一阶段互射，可主动中止任务；基本规则下主动中止直接避开此次攻击。
6. 幸存 Strike 若未中止且还有未损坏步，可继续任务；其他中队回 Used 或原制空区。

Ferry 不能截击；可选 Recon 任务也不能截击。截击经常在不知道具体任务和精确目标时就要投入稀缺中队。

可选规则：**Intercept Pursuit** 下主动中止的 Strike 掷骰 ≥9 才能免受追击射击，但无论骰值仍必须中止；**Attack Squadron Splitting** 允许完整、无损坏截击中队分占两个相邻攻击位置，攻击两支 Strike，但击毁转损坏、损坏结果忽略。

来源：§24.20，pp.27–28；§24.25，p.29。

## 10. 1985：全部固定翼任务

### 10.1 通用任务骨架

多数突击任务先分配 Strike 与 Escort，宣布大区域和中队数量；经 Transit 防空、敌方截击后，再公布精确目标，接受 Ingress 防空，最后执行任务。这样敌方在投入截击时通常不知道精确目标和完整中队性能。Wild Weasel 改用 On-Station；制空、Ferry、Recon、海军攻击有专门流程。

通常最多 6 Strike + 6 Escort + 对方 6 Intercept；Ground Support 上限均为 10。ECM 作为附加中队不占任务中队上限。不能把这些上限当成每回合可执行的任务数量：任务次数仍受可用中队与任务时机约束。

来源：§24.9–24.21，pp.24–28。

### 10.2 对地支援、地面打击与补给阻断

| 任务 | 时机与效果 | 关键细节 |
| --- | --- | --- |
| Ground Support | 地面战前，进攻方先、防御方后；幸存 Strike 值加入己方 Combat Value | 每方每场战斗最多一次，失败不能补做；直升机支援不占这一次；最多 10+10+10 |
| Ground Strike | 移动/SF Raid 步开始，或行动方完成一个战斗单位移动后；双方都可执行 | 每个幸存 Strike 中队分别掷 Ground Strike 表；最多 6+6+6 |
| Supply Interdiction | 西方在东方移动步开始，要求揭示 Front Supply Head 的补给路径，攻击沿路格 | 按 Ground Strike 流程；表上红色结果使所有使用该路径的 FSH 本回合被阻断；不需 Recon |

Ground Strike 结果：`5/10` 增加离格/单位组移动成本，累计最多 +20 MP；`+` 可损坏基地/桥/岸炮、消灭固定 SAM、迫使 FSH 位移，或摧毁最多 5 储存补给点；`1` 增加 +10 MP 并造成一步战损，无战斗单位时可损伤支援单位或选择 `+` 效果。目标有任一战斗单位处于 Road Mode 则掷骰 +4；全部战斗单位 Hedgehog 则 -3。阻滞标记持续当前及下一个 Action Phase，在下一行动阶段 Removal Step 移除。

Supply Interdiction 在标准补给规则下，使相关地面战斗单位在作战地图最多移动 3 格、不能在 LOC 移动，敌方战斗修正 +2。详细补给规则下改为最多 2 格、敌修正 +4，FSH 最多为 10 个师补充携行补给；携行或库存补给可按规定克服相关限制。这里主要削弱当回合依赖某条供应线路的部队，和 NATO 游戏扣下回合新增补给点的机制不同。

成功地面 EW 会把敌方 Ground Support 减半；地面支援不能只算中队 Strike 值而忽略战场电子战。

来源：§24.9–24.10，pp.24–25；§24.17，pp.26–27；§9.15，p.11；§15.1，p.16。

### 10.3 压制防空

| 任务 | 条件与结算 | 效果 |
| --- | --- | --- |
| SEAD | 普通突击流程，最多 6+6+6；每个幸存 Air Group 把 Strike 相加攻击一支防空/舰艇，可重复攻击同目标 | `S` 压制本 Action Phase；`SD` 消灭 SAM/ADA，压制部队自带防空；舰艇防空和导弹防御都被压制 |
| Wild Weasel（可选） | 必须至少有 W 中队完成；可带非 W 中队；目标只能是没有敌方制空的作战地图 Megahex；经过航路、截击、留空防空 | 有 W 中队保留未损坏步即建立本回合 Wild Weasel 区；区内敌防空最大射程降为 1，对区内飞机射击掷骰 +2 |

SEAD 可在移动/SF Raid 步开始、完成战斗或海军单位移动后、宣布地面战斗后执行；Wild Weasel 无后一种宣布地面战斗后的专门时机。SEAD 带 ECM 的任务完成掷骰：北约 +3，其他 +2。ECM 不能加入 Wild Weasel。

来源：§24.11–24.12，p.25。

### 10.4 转场、空运、空降、再补给

| 任务 | 条件与到达效果 |
| --- | --- |
| Ferry | 单个中队在有效基地间转场，无 Combat Radius 限制；起止基地不能在敌制空区；到达 Used；不接受敌方截击 |
| Air Transport | 己方移动步执行；两端基地未损坏、无核污染；乘客在起始基地、Tactical Mode、非未被友军抵消的 EZOC；落地后本 Action Phase 不能再移动 |
| Airdrop | 只运 Airborne、Special Forces；起点 General Supply、Tactical、无未抵消 EZOC；耗乘客 5 MP；只落指定平原、沙漠、粗糙-1、城市类型或陆地 LOC；不能落敌军或守备基地，坏天气禁止 |
| Air Resupply | 运力转换为补给点；可到友控机场、指定地形的安全友控格或陆地 LOC 的部队组；使用空运任务流程 |

同一基地起飞的运输中队可合并运力；旅/团每损失一步运输成本 -1，师每步 -3。Air Transport、Airdrop 最多 6 运输 Strike +6 护航+6 截击。每一步运输机被**击毁**，乘客损失一步；余下运力仍不足时，乘客继续减员至运得下；全部运输机击毁时乘客消灭。

空降到敌 EZOC 的空格，另外掷 d20：1–10 再损失一步，11–20 无此损失；必须立即攻击投射该 ZOC 的敌军。与 NATO 游戏不同，1985 的普通空降不能直接落在敌军占据格。

Air Resupply 在完好机场完整卸货，其他目的地仅获得幸存运输容量的 1/3。从基地生成并装载的当回合补给受共同装载限额约束：连到北约/华约来源的 General Supply 基地每回合 10 点，Limited 3 点；不连到该类来源但 General 的基地 1 点。回合开始已有的库存补给可不受此生成限额装载；飞机、直升机、船共用这个基地限额。

来源：§24.13–24.16，pp.25–26。

### 10.5 战略空运与人员空运

Strategic Airlift Points 是剧本/动员提供的重型军民运输能力，每点每回合用一次，可集中投入一次普通 Air Transport，可护航、可被截击，不能积累。

若被截击，每点表示一架抽象 `T-1-0` 飞机步、容量 1；每两点组成一个完整运输中队。每个战略运输机步被击毁，**该方以后回合的战略空运能力永久减少 1 点**，不只是丢失本次货物。

Personnel Airlift 把人员送到已海运或预置装备的单位，移除 Equipment Only：装备须在友方完好机场 4 个 Road Mode MP 内，或位于有完好友方港口的 LOC Box。成本用 Ship Troop Transport Cost，零成本单位仍耗 1/2 Airlift Point。运输成功后单位当回合不能移动，被迫移动则消灭；途中乘客损失由等待人员的装备单位承担。纯装备单位在人员到达前不能移动、作战、投射 ZOC，被敌战斗单位攻击或进入就消灭。

来源：§24.23，p.29；§26.4.2，p.33。

### 10.6 侦察（可选）

启用 Recon 后，对作战地图格实施 Ground Strike、SEAD，一般先要侦察成功。例外是邻接己方占据格；仅打击本行动阶段已经开火的防空；仅打基地、桥、岸炮、固定 SAM。Supply Interdiction 明确免侦察。

每次一个 R 中队，不可被截击，但接受航路及进场防空；只有 A+、A、B 防空能对 Recon 的进场开火。还有未损坏步就检定目标是否被发现：规则规定华约 1–6、其他国家 1–3 为未发现，其余成功。Spotted 标记在回合结束移除；侦察机回基地 Used。

来源：§24.25，pp.29–30；§24.17.1，p.27。

## 11. 1985：地面与舰载防空

### 11.1 类型、射程和弹药

| 防空类型 | 对飞机的规则 | 弹药/补给 |
| --- | --- | --- |
| 固定 SAM、机动 ADA | 独立一步支援单位；射程印在算子上 | 初始 3 Flak Ammo，每次射击耗 1；每单位占半个旅堆叠 |
| 部队自带 A+/A/B | 射程 3 格，可参与航路、留空防空 | 3 Flak Ammo；耗尽后可按低等级自带防空条件使用 C 级能力 |
| 部队自带 C/D | 通常有 ZOC 的单位射程 1；通常无 ZOC 的射程 0 | 不耗专用 Flak Ammo，但须有补给或至少 1 携行弹药点 |
| LOC、图外基地固有防空 | 只保护对应 Box/基地目标；不能摧毁，可压制 | 不耗 Flak Ammo；敌方占领后按相应固有防空规则处理 |
| 舰载 A+/A/B | 未靠港时对飞机射程 0；舰队攻击另有分层射击 | 使用舰艇弹药衰减规则；不能用舰载 Flak 对直升机射击 |

回合结束：General Supply 防空补满，Limited 补 1 点；库存补给可按每个 Flak Ammo 1 补给点恢复。支援防空被地面攻击、SEAD、核打击、特战袭击摧毁后不是自动下回合重生。

LOC 固有防空：苏联/华约 Box 为一份 B；北约 Box、含北约港口或补给源的 Box 为一份 A。图外基地按 holding box 印刷能力处理。

来源：§16，pp.17–18；§12.2.3，p.13；§14.2，p.15；§27.4.2，p.36。

### 11.2 三个固定翼防空窗口

| 窗口 | 何时触发 | 火力分配 |
| --- | --- | --- |
| Transit Flak | 航路穿过有防空的 Megahex，尚未到最终目标区 | 仅 A+/A/B；一支防空攻击一个经过中队；各中队先各受一次，才可重复分配；该防空不能在同任务序列再次射击；始终应用 SAM Belt 修正 |
| On-Station Flak | 制空/截击中队留空，或任务目标是整个 Megahex | 仅 A+/A/B，须实际位于任务 Megahex；每支防空攻击一个中队，先均分目标 |
| Ingress Flak | 已公布精确目标格、基地、舰船后的进入目标防空 | 射程覆盖目标，或按 LOC/基地资格参与；每支符合条件的防空可对每个 Air Group 射击一次，前提是弹药足够；使用组平均 Evasion |

按防空等级列、规避与其他修正掷 Flak Table，立即执行损失。目标方通常可以在遭受 Transit/Ingress 前选择让全部或部分固定翼中队中止，改放 Used；直升机不能中止以规避进场防空。不能将同一防空、同一窗口或各类窗口的资格混为一谈。

来源：§16.1，pp.17–18。

### 11.3 对直升机的防空

直升机逐标准格移动，一进入防空射程立即独立受射击；不按 Air Group 分组。每支防空对一个连续经过其射程的中队只射一次；退出再进入可再射。

- SAM/ADA 对正常飞行直升机射程 1 格；A+/A/B 降用 C 级并消耗 Flak Ammo。
- 高等级部队自带防空同样按 C 级对直升机开火，但不耗专用 Flak Ammo；仍受基础补给条件约束。
- NOE 超低空飞行使所有防空射程降为 0，必须进入防空所在格才触发；地面战中进攻部队自带防空及同格防空，对支援防御的 NOE 直升机有专门例外。
- LOC 防空须属于攻击/防御部队才能对直升机射击；基地防空在直升机进入/支援该基地战斗时使用；舰载 Flak 不攻击直升机。

来源：§16.2，p.18。

## 12. 1985：直升机运输、攻击与特战

### 12.1 任务频率、基地与移动

直升机每个 Action Phase 可执行一次任务，所以在己方、敌方行动阶段各有一次机会。任务为移动到目标、受沿途防空、执行任务、再移动到有效基地；不能安全返航则消灭。可在己方移动步转场或运输，在地面战中提供 Strike 值支援，在特战袭击步运输特种部队。

直升机移动值是**整个任务的总移动力**，不是单程半径：正常每格 1 MP，NOE 每格 3 MP，可随时免费切换。LOC Connection 30 MP，图外基地进出按 8×Entry Distance，图外基地与关联 LOC 间 4 MP；Sea Box 不能结束移动，除非在适当舰船上着舰。普通移动力少于 30 时，有使用全部移动力到相邻陆路 Box 的例外。

有效基地包括友方机场、直升机场、允许的友控地形格、符合国籍/控制条件的 LOC、配属航母、带适当直升机甲板的舰艇。野外一个格最多基地化 2 中队；普通白色甲板可驻 1 中队，另加指定属于该舰的配属中队。起止基地是否有效在任务开始前检查。基地失去资格时，尚未移动的中队可紧急转场，否则消灭。

机场/直升机场国籍匹配时可执行对应类型全部任务；外国籍机场只能运输、转场；损坏或核污染基地只允许转场。

来源：§25.1–25.3，p.30。

### 12.2 遭遇敌制空区与损失

进入敌制空区的瞬间，按 Helicopter Interception Table 检定；以中队 Evasion、全程保持 NOE 等修正。存活后在该区内继续移动不再检定，离开再进入或进入另一敌制空区则再检定。它独立于沿途地面 Flak。

直升机通常两步，所有 Damage 结果转为永久步损，不存在飞机那种可修理损坏状态。同国籍、同类型、同基地的两个残余中队可在移动步开始合并。

来源：§25.4–25.5，p.30。

### 12.3 运送部队与补给

有 Transport Capacity 的直升机可运表允许的部队。共同起飞可合并容量，整队按最慢中队移动力飞行，但防空、截击和损失仍分别处理。一般装/卸各 3 MP，舰艇甲板各 6 MP；被运部队耗 2 MP，不必预先与直升机同格，须 Tactical、无未被其他友军抵消的 EZOC。

每两步运输直升机因 Flak 损失，乘客损失一步；运力不足还要继续减少乘客步数，全部运输直升机被 Flak 击落则乘客消灭。普通机场、LOC、无敌 ZOC 的空格卸载后可继续移动；卸在敌 ZOC 空格则必须立即攻击投射 ZOC 的敌军，只有 `D` 结果后允许继续移动。

可装补给的地点为友方机场和带白/蓝直升机甲板的舰艇；舰艇只能转出既有库存。可卸到允许地形、友方机场、合适 LOC 或舰艇。途中补给数量随运输机损失调整；机场新生成补给仍受 10/3/1 的共同装载限制。

来源：§25.6，pp.30–31。

### 12.4 北约机动反坦克营

有指定 `A` 标记的北约空中机动旅可在敌方地面攻击时派出一个营增援防御。旅须 General Supply、Tactical、非敌 ZOC，本行动阶段未被攻击或派营；与至少 1 营容量的未用运输直升机同格；目标防御方须有战斗单位。

直升机按正常移动、防空、敌制空截击飞到战斗格。两步及以上运输损失使营任务失败并使母旅损失一步；成功时防御总值 +1、战斗修正 +1。母旅不实际移入战斗格，直升机在战后撤退/推进前回原机场。最终战斗结果为 `D`，母旅还需损失一步。多个营不能叠加效果；同一母旅本行动阶段不能反复派营。

来源：§9.13，p.11。

### 12.5 特种部队直升机袭击（可选）

SF Raid 步开始一并计划特战部队、运输机和目标格/LOC 部队组/图外基地。去程照常受 Flak，运输直升机每步损失使特战部队损失一步；抵达时另按目标防空进行 Raid Ingress。与敌特战单位相遇还要相互消耗特战步数。

袭击成功后，每支幸存特战单位可选择消灭一支飞机/直升机中队，或摧毁两步支援单位、损坏一个基地/桥、消灭港内两步舰艇、毁掉最多 5 库存补给。目标处每个敌旅当量还导致两步特战损失，师算三个旅。幸存者再乘直升机返回；刚遭袭目标格的防空不能再攻击返程，其他沿途防空仍能开火。

来源：§15.6，p.17。

## 13. 1985：电子战、预警与隐身

### 13.1 ECM

ECM 可附加到除制空、Wild Weasel 外的航空任务，不占中队上限，不可被攻击或迫使中止；任务后回 Used。它改善截击空战、抵御 Flak，并为 SEAD 提供额外修正。多支 ECM 不叠加效果。地面 EW 单位是另一套战场规则，会削减 Ground Support，不要与 ECM 中队混用。

来源：§24.21，p.28；§9.15，p.11。

### 13.2 AEW / AWACS

AEW 按战区而非某个基地部署：AN 为 DNL 北方，AC 为 UAIS 中央，CC 为 SO 南方。它只能支援所在 Air Theatre 内全部或部分覆盖的制空区；改善区内空战和目标在该 Megahex 的截击概率。未分配的 AEW 在制空阶段结束后可改驻另一个战区。

海上 CV/CVN 所在 Megahex，在没有敌制空时视为有己方 AEW；在 LOC 中，其 AEW 只支援该 Box 内涉及本航母配属飞机的任务。不能把舰载 AEW 当成可任意部署的陆基 AEW 中队。

来源：§24.24，p.29；§26.15，p.35。

### 13.3 隐身

只有任务所有友方中队均具有 Sh 才算隐身任务，不能给普通轰炸机配一个隐身护航就全队隐身。

- 从制空区截击隐身任务也需掷骰，18–20 才成功，不再自动截获。
- 从基地截击额外 -12 修正。
- 对一方首次隐身任务，敌 Flak 完全不能射击；第二、第三次可射击但 +10；第四次以后 +8。这是按一方实施隐身任务的次数推进，不是每回合重新开始。

来源：§24.22，pp.28–29。

## 14. 1985：机场、补给、损伤与补充

### 14.1 驻扎和保障

固定翼任务须从有效基地开始、在有效基地结束。有效基地包含友控机场、符合条件的 NATO/WP 陆地 LOC，以及与飞机 Setup Code 匹配的航母。LOC 或外国籍机场驻扎的中队只能运输、转场；机场同国籍/联盟国籍时可正常执行任务。

机场有 Support Capacity，未印值时默认 10 中队；超额者只可 Ferry。直升机场容量 4 中队；野外直升机基地另按第 12 节容量。

基地补给在飞机起飞时检查；General、Limited Supply 的航空行动没有普通能力惩罚，Out of Supply 只能 Ferry。标准补给规则下，空运乘客本回合保留装载时的补给状态，下一回合空降/空中机动/海军陆战/特战部队在没有敌制空的格可得 Limited Supply。详细补给替换这些自动待遇，并允许库存补给支撑任务：每中队每任务 1 补给点。

来源：§24.1，p.22；§25.2，p.30；§27.1–27.2，p.36；§13–14，pp.13–16。

### 14.2 损伤、修理与替补

飞机 Damage 与 Destroyed 对当前可用能力影响相同，但 Damage 可修理；全部剩余步损坏的中队只能转场或在任务中返航。直升机没有 Damage，直接转步损。

回合结束按机场 Repair Capacity 修复损坏飞机步，机场须完好、General/Limited Supply、无核污染；未用容量不积累。同类型同国籍的残余飞机中队可以在同行动阶段开始、同机场时合并，保留已有损坏。

Air Replacement Points 在替补步使用，不积累；1 点同类飞机替补恢复一步。可以重建已消灭的中队，放在符合供应、未损坏、无敌 ZOC/敌制空条件的友方机场。这与 NATO 的 Command/攻击直升机被消灭后永久失去不同。

来源：§24.6，p.23；§25.5，p.30；§19.2，p.19；§27.1.2，p.36。

### 14.3 基地损坏、占领与启用

地面突击、特战、Ground Strike、核打击都能损坏机场。损坏机场的飞机、直升机只能 Ferry，不能修理飞机。机场遭地面攻击时，未使用且符合资格的航空单位可支援防御或转场，支援后也可去其他基地；机场最终被占领时还在里面的航空单位消灭。

占领机场失去原国籍，须启用才能完全使用。满足友军地面存在/控制与供应条件，在 End Phase 支付 5 Repair Points 或 10 库存补给启用；获得阵营国籍，保留保障容量，但被占机场原有正修理容量变成 1，原来 0 则仍为 0。友好国达到 Commitment 3 的机场也可启用，保留原修理容量。

直升机场占领后视为损坏，启用成本 2 Repair Points 或 5 库存补给。损坏机场一般修复需 5 Repair Points；核污染区修复成本翻倍。基地是有守备的地面目标，可以通过航空支援抵抗没有其他地面部队的突击。

来源：§27，pp.35–37；§29，p.37。

## 15. 1985：海空任务及舰队防空

这些属于同一规则书的系列机制，具体 UAIS 场景是否使用取决于海军与航空配置。

### 15.1 海军打击

双方可在移动步执行 Naval Strike，最多 6 Strike、6 Escort、6 Intercept。航空 Transit/空中截击后揭示舰艇或 Task Force，先进行海军目标截获检定，不能使用主动辐射；未截获的飞机回 Used/原制空区。

St 中队按导弹攻击程序在防区外攻击，经过舰艇/舰队导弹防御；普通 Strike 编成 Air Group，由外向内穿透目标舰队，进入每层受该层舰艇 AA。单舰海上目标由该舰进行 Ingress，港内舰艇按进场防空。每支幸存 Strike 分配目标舰，再按 Naval Combat Table、舰艇 Toughness、Detection Level 结算；Detection ≥2 的舰队可选择舰，港内舰艇目标随机选择。

Task Force 有 Outer、Inner、Core 三层；内层防空额外受外一层舰艇数量影响；目标 Detection 3 时 Outer 防空另 +3。舰载 A+/A/B 在防空/导弹防御掷出 1–8 时，按海军弹药规则降低一级能力，直到满足再装填条件。

来源：§24.19，p.27；§26.6，p.33；§26.10，p.34；§26.13，p.35。

### 15.2 航空布雷、海上监视与反潜

- **Minelaying**：按 Ground Strike 流程，仅在作战地图；每个幸存且 Strike ≥5 的飞机步，目标格水雷等级 +1，最高 3。
- **Naval Surveillance**：抽象海上侦察区，基地距离最多 4 Megahex，提高敌水面舰艇 Detection。
- **ASW Surveillance**：抽象反潜巡逻区，基地距离最多 2 Megahex；提高截获潜艇机会，每 Action Phase 可对区内一支潜艇尝试截获一次，成功后以 ASW 值 6 攻击。
- 两种巡逻依赖完好友方机场/海军基地和相应外交资格；不能在坏天气或敌制空区建立，相关条件失效即移除。双方可以在同一 Megahex 各有巡逻区。
- 航母提供 AEW 与特定飞机、直升机的海上基地，舰艇受损可能降低其基地保障/修理能力；带直升机甲板的船还参与运输与补给。

来源：§24.18，p.27；§26.7，p.33；§26.1，p.31；§26.15，p.35；§25.2、25.6，pp.30–31。

## 16. 1985：天气、WMD、外交与增援

### 16.1 天气（可选）

天气分 Good、Bad，按欧洲、北极、海湾区域分别确定，只对作战地图施加天气效果。

- Li 飞机在坏天气不能出任何任务。
- Ground Support、SEAD、Ground Strike、Recon、Naval Strike、Wild Weasel 出动前掷骰，1–10 中止；相应中队本回合不能再次检定同类天气要求，但还可做不需要此天气检定的护航/截击等任务。
- 坏天气不能空降；直升机移动前掷骰，1–10 中止、本移动步不能再移动。
- 海上巡逻不能在坏天气区放置。

来源：§30，pp.37–38；§24.15，p.26；§26.7，p.33。

### 16.2 核化战争（可选）

苏、美、英、法 Strike ≥3 的飞机可以用 Ground Strike、Naval Strike 投送核武，仍要经历普通任务的航路、截击、防空。Ground Strike 中一个合资格中队投送的 Nuclear Pulses 数量不另设中队上限，但受该方航空投送核资源总额限制。地面核攻击按送达脉冲数掷表分配损失；损坏基地或桥需分配两步损失。海上核攻击在海战表上每脉冲 +4，不生成海上核污染。

核污染机场/直升机场只允许转场，禁止飞机损坏修理；§22.5.3 还明确要求核污染中的固定翼飞机转场时，所在机场必须完好。基地/桥修复成本翻倍。核使用推动紧张等级，并可结合 Strategic Escalation 处理升级后果。

启用 Strategic Escalation 时，航空核任务还受政治释放权限约束：首次使用某类 WMD 前，在 WMD Release Phase 请求并查表；一方获准后，另一方下回合按相应回应表检定，即使前者实际上没有投放。释放可能引发战略核交换，此时最先请求释放 WMD 的阵营遭决定性政治失败。剧本已授权的特定国家另按专门规则，不自动触发这一升级链。

华约 SSM 化学攻击可打机场、直升机场与防空：使用受影响的航空中队前按 SSM Chemical Strike 表检定，失能后本回合不可用，但转场免检；对支援单位含 SAM/ADA 则影响当前宣告的战斗或航空任务。化学污染也不能用于补给路径，间接影响航空基地和防空补给。此规则并不是一个 NATO 式“直接减全军航空点”的效果。

来源：§21–23，pp.20–22；§22.2–22.5，pp.21–22。

### 16.3 国家空域、交战与承诺等级

国家领土和完全位于其中的 Megahex/对应 LOC 定义国家空域。航空航路、驻扎和发动攻击还受政治许可限制，拥有足够航程不等于有权限使用外国基地。

| Commitment | 对友方阵营的航空意义 |
| --- | --- |
| 0 Neutral | 无空域、领土、基地准入 |
| 1 Friendly | 允许飞机、直升机过境空域，不给领土/基地准入 |
| 2 Supporting | 允许空域和基地使用、补给通路；从该国起飞攻击仍受该国交战状态限制 |
| 3 Active | 全面友方准入，可把机场启用为阵营基地，建立海上/反潜巡逻 |
| 4 Allied | 加入阵营、按共同交战状态行动，单位获得对应阵营准入 |

未互相交战的国家不能攻击彼此部队/基地。混合任务只要含有与某国交战的单位，整组按交战状态可被该国攻击。飞机/直升机通过海上 Connection 穿过外国 LOC 有特例，但无准入不能在那里停留/降落，可降己方海上舰艇；地面、直升机不能随意进入敌方 NATO/WP 战略 LOC。

事件卡、动员、紧张局势、外部战线可改变航空增援、战略空运及资源分配；具体由剧本/事件规则给出。

来源：§31–33，pp.38–39。

### 16.4 航空与空中部队增援

固定飞机增援一般放于完好、无敌 ZOC、无敌制空的机场；直升机还需相应基地能追溯有效补给路径。空中机动、空降、特战地面增援可按规则进入可执行空运的机场、直升机场或 LOC。指定入口不可用时允许延迟。事件、动员、预备增援可能改变到达时间、地点和政治准入，不能把所有增援都当成无需风险的自由基地补充。

来源：§18，p.19。

## 17. NATO：一回合行动流程与示例

### 17.1 航空行动在回合中的位置

NATO 的固定翼攻击并不需要先把飞机从机场移到目标，也没有玩家逐中队执行的制空战阶段。按航空相关内容，可以把正常回合理解为下列流程；完整回合中仍有其他地面、动员与战斗环节。

| 环节 | 航空相关处理 | 玩家需要判断的内容 |
| --- | --- | --- |
| 联合状态 | 上回合用过且符合恢复条件的 Lift Command、攻击直升机恢复 | 哪些运力、攻击直升机还存活；Surprise 是否延迟美军旅恢复 |
| 联合增援 | 接收增援；按剧本航空战役表得到本回合点数，应用永久削减 | 年份、战争回合、War of Nerves 的双方选表；核武造成的削减 |
| 华约移动 | 空中再补给；空海 Ferry/Transport；直升机投送、撤出 | 当前空域、乘客资格、运输拦截、航路 Flak、成组行动的预先声明 |
| 华约进攻打击 | 按核、化学、空袭、炮兵顺序打击 | 先计划全部本段空袭；战术/战役点是否合资格 |
| 华约战斗 | 北约防御核/空袭；双方合资格攻击直升机进入战斗 | 北约最多两战术点打当前参战攻击者；攻击直升机是否能抵达、存活 |
| 华约预备 | 合资格预备部队可作缩短的直升机投送 | 只能投送，5 格航段，不能直接发动 Assault |
| 北约移动、进攻打击、战斗、预备 | 执行对应本方行动；北约可作纵深补给阻断 | 前面防御已用了多少航空点；华约没有防御空袭和防御攻击直升机任务 |
| 下一回合恢复 | 回收航空资产，重新产生航空点 | 未用航空点不会结转；永久损失的 Command 不能恢复 |

来源：Living Rules §7，pp.25–29；§15、18、20、23。此表省略不涉及航空的环节，不改写完整回合顺序。

### 17.2 示例：航空点在防御和进攻之间分配

假设北约本回合获得 **6 战术航空点、2 战役航空点**。这是讲解用的假设收入，不是指定剧本的实际表项。

华约首先对两个地点分别发动地面攻击。北约在第一场战斗花 2 战术点、第二场再花 1 点做防御空袭，就剩 3 战术点、2 战役点。第二场没花满 2 点并不会把该场的“未用额度”变成额外资源；点数只来自回合航空池。

轮到北约自己进攻时，可以把剩余 3 战术点打向合资格的前线目标，把 1 战役点压制一个华约 HQ，另 1 战役点用于纵深补给阻断。也可以把两战役点都留给一次更大投入的纵深阻断。选择某种任务意味着放弃同一点数的另一用途。

这说明北约的防御空袭是时间上的灵活性，没有额外生成一个防御点数池。战役点不能补充防御空袭额度；华约虽持有航空点，也不能照北约的方式在对方战斗周期中使用。

来源：§23.1–23.2、23.5、23.7。

### 17.3 示例：同格多个单位如何空袭

假设某目标格中有：完整两步师 A、一步旅 B、一步旅 C，总共四步。

玩家投入两航空点时，应将它们组织为两次独立空袭，例如第一次打 A，第二次打 B+C。假设查表得到第一次 `D1`、第二次 `*`，则 A 翻为一步残部并混乱，B、C 都混乱。不是一次“四步目标、两点火力”的合并结算。

另一种分配是只打 B，再打 C，让 A 不受空袭；但不能第一次打 A 完整师，第二次马上再打同一师的残部。该单位在这个空袭段已经被攻击过。

若格中还有 HQ，专门打 HQ 的那一次必须使用战役航空点，且不能顺便包含 B。若只有一个两步师，也不能为了多消耗点数而在这个段对它做两次常规空袭。

来源：§23.1.5、23.3、23.5。

### 17.4 示例：运输拦截的判定与损失

假设一支一步空降部队使用一个 Airlift Command，进入敌方空域，落点在 EZOC。再假设按正式表查得此次阈值为 **5**；这里的 5 是示例输入，不是固定空降阈值。

- 掷 2d6 得 3+3=6，因落点 EZOC -1，最终为 5：不大于阈值，截获成功，空降部队与 Airlift Command 一起永久消灭。
- 掷得 4+3=7，修正后 6：超过阈值，运输成功，部队落地，Command 进入 Recovery。

目的格即使已有友军，也不移除这个运输拦截的 EZOC 修正。与此同时，友军存在可能改变直升机的 Flak 资格；两类风险不能共用同一项“友军掩护”判定。

若无其他修正，阈值 5 的 2d6 截获概率为 `10/36`；带 EZOC 的 -1 相当于原骰不大于 6，概率为 `15/36`。这些概率说明修正的影响，不代表任何剧本都使用阈值 5。

来源：§17.1。

### 17.5 示例：直升机去程与返程承担不同损失

假设一次 Insertion 去程经过两个危险 EZOC 格，抵达卸载格后还要空机穿过一个危险格返航。去程任一格被击落，乘客随 Command 消灭；成功卸载后，返程被击落只消灭 Command，落地部队保留。

如果改成 Extraction，去程空机穿过同样危险格被击落，只丢失 Command，等待撤出的乘客仍在原格；接到乘客后返程被击落，乘客才随它消灭。不能仅按整个任务有没有 Flak 损失来判断乘客命运，必须知道发生在哪条航段和是否已经装载。

再假设连续向同一个空 EZOC 格投送两支部队。第一支成功落地后，为第二支进入该格提供掩护；第二支沿路其他危险格仍照常受 Flak。若目的格本身有敌军、行动属于 Assault，第一支突击部队不会为第二支解除目标格的防空风险。

来源：§18.1、19.1.3–19.1.5。

## 18. 1985：完整任务流程与计算示例

### 18.1 在选择目标前，先检查任务能不能成立

1985 的任务资格由多个条件共同决定，不是仅检查目标是否在航程内。

| 检查 | 不满足时的后果 |
| --- | --- |
| 国家是否交战、是否有过境/基地许可 | 航路或攻击不合法；政治许可与制空权是不同问题 |
| 中队类型是否允许任务 | B、R、N、T 等不能通用地改做所有任务 |
| 中队是否 Ready，或合资格地驻在制空区 | Used 普通中队不能本回合再次起飞；制空区重复任务仅限规则允许的截击/护航 |
| 基地国籍、保障容量、损坏与补给 | 外国籍、超额、损坏、缺补给等可能只允许运输或 Ferry |
| 是否有符合要求的航路与返航基地 | 超出延伸半径不能执行；去程可达不表示返程自动合法 |
| 任务专门条件是否满足 | Recon、空降地形、运力、天气、目标发现等分别检查 |

因此，一个攻击性能很强的中队仍可能因为驻扎在外国籍机场、已在前一任务进入 Used，或无法返航而不能打击目标。任务计划需要同时安排基地、航线和中队状态。

来源：§13、24–25、27、30、32。

### 18.2 示例：航程、延伸半径与长航程能力

假设一中队对某任务的表定标准半径为 **4**，原始 Attack=7、Strike=5。以下是教学用性能，并非某种实际飞机的算子值。

| 到目标的航路长度 | 是否可执行 | 任务中使用能力 |
| --- | --- | --- |
| 4 | 可以，标准半径 | Attack 7、Strike 5 |
| 6 | 可以，延伸半径，上限 8 | Attack 5、Strike 3 |
| 9 | 不可以 | 超过两倍标准半径 |

如果该中队有 Rn，标准半径变为 8、延伸为 16，长度 6 就不再付出 -2 的代价，长度 9 则成为延伸任务。Rn 增大的是任务半径，不是额外增加一次出动，也不让整支编队的其他中队自动获得相同航程。

假设另一中队由图外基地起飞，入口距离为 2，再进入 3 个后续 Megahex，其到目标路径为 5。返航可选择另一个基地，但目标到该基地仍须在本任务使用的半径内。不能把“起飞到目标的距离”和“全部往返距离”相加后，按直升机总 MP 的方式处理固定翼任务。

来源：§24.4。

### 18.3 示例：制空战如何选列与加修正

假设两个普通战斗机中队匹配在同编号位置，甲方 Attack=7，乙方 Evasion=4，则甲方用 `7−4=3` 对应的 Air Combat 表列。甲飞行员等级 4、乙等级 3，甲方另获 +1 掷骰修正。

若甲方有适用的北约 AEW 支援、乙方没有，则甲方再 +2；若本轮甲方未损坏步数达到乙方两倍，则再 +2，总修正为 +5。这里增加的是骰值，不是把表列从 3 改成 8。

乙方也独立用自己的 Attack 减甲方 Evasion 选列，并按从乙方射击角度适用的修正掷骰。双方损失同时执行，不因先读取甲方结果就取消乙方这一轮的射击。某中队因中止或没有未损坏步退出后，下轮双方重新编组，并重新比较数量优势。

来自制空区的截击优势只用于 **Intercept Combat**；不能在这场争夺制空权的战斗中，再因为“正在制空区内”额外加一次该修正。

来源：§24.7–24.8。

### 18.4 示例：一次地面打击会遇到哪些防御

假设西方派 3 Strike、2 Escort，并附加 1 ECM 执行 Ground Strike，目标为敌方一个 Megahex 内的地面格。

1. 检查每个中队的类型、基地、状态、半径；若使用 Recon 可选规则，确认精确目标具有合法发现条件。
2. 公布目标大区域和 Strike/Escort 数量，不提前把精确目标和全部性能都交给对方。ECM 不占 6 Strike/6 Escort 上限。
3. 敌方沿途 A+/A/B 防空在符合 Transit 条件的区域开火；任务方可以按规定中止部分中队。
4. 敌方投入不超过本任务上限的截击中队。基地截击者先检定能否截获，再经过自己的防空窗口；制空区截击者按专门待遇。
5. 先结算护航与截击者交战，再由成功 Evade 的截击者攻击 Strike。损伤、中止决定哪些 Strike 还能继续。
6. 揭示精确地面格，符合射程的敌方防空对幸存 Strike 编成的 Air Group 做 Ingress。
7. 每支仍可继续的 Strike 中队分别按 Ground Strike Table 结算，应用 Road、Hedgehog 等任务修正。
8. 记录战损、基地损坏或移动阻滞；参与的普通中队回有效基地 Used，ECM 也回 Used。

这条链条解释了为什么单看轰炸机 Strike 总值不能预估最终打击量：中队可能在到目标前已经中止、损坏或被击毁。护航并不替 Strike 承担所有进场防空，ECM 也不等于任务免疫防空。

来源：§16.1、24.10、24.20–24.21。

### 18.5 示例：截击者为什么要选择 Engage 或 Evade

假设一支截击中队成功接敌，面对一支护航中队和其后的运输中队。

| 选择 | 护航阶段 | 后续能否攻击运输机 |
| --- | --- | --- |
| Engage | 双方可互相攻击，截击者试图打掉护航 | 不能；该中队已放弃攻击 Strike 的机会 |
| Evade | 截击者承受护航攻击，但自己不对护航开火 | 存活且未被迫退出后，可以进入攻击阶段 |

Evade 在规则上不是“成功掷一个躲避骰就免伤”，而是选择不与护航纠缠，以保留攻击任务机的资格。护航中队的价值是把截击方迫到这个取舍上：要么打护航、放过 Strike，要么冒着单方面受火力的风险冲过屏障。

任务机在攻击阶段可主动中止。基本规则下因此避开该次射击；启用 Pursuit 可选规则后，主动中止还须掷 ≥9 才能先脱离。中止的运输任务没有完成，即使飞机本身存活也不算把货物成功送到目的地。

来源：§24.20.1–24.20.2。

### 18.6 示例：Air Group 与防空弹药

假设三支中队 Evasion 分别为 5、4、2，编成一个 Air Group，平均为 `11/3`；按通用向下取整规则得到 3。Ingress 按该组规避能力及防空修正处理。损失尽量平均，首先分给规避值最低的中队。

如果把三支中队拆成三个各含一中队的 Air Group，不意味着面对同一防空时总是更安全。Ingress 规则允许一支有足够弹药的防空对每个 Air Group 各射一次：它可能用三发弹药打三个组。合成一个组时通常只对这个组射一次，但组内低规避飞机会拉低平均能力。

这是一种编组和防空消耗之间的取舍。Transit 则不是按 Air Group 平均值射击：合成一组不能把航路防空也自动变为单次组攻击。弹药耗尽会改变后续任务的防空环境，但高等级部队自带防空的 C 级后备能力仍要单独检查。

来源：§3.4、16、24.5–24.6。

### 18.7 示例：SEAD 与 Wild Weasel 如何配合后续行动

假设一个关键目标格附近有长射程 SAM。先派 SEAD，通过截击和防空后，假设表上得到 `S`，该 SAM 在**当前 Action Phase** 不能开火。接下来在合法时机执行的 Ground Strike、Air Transport 或 Ground Support，可利用这段压制窗口；到了下一 Action Phase，不应仍把该 SAM 当成被压制。

若得到 `SD` 且目标是独立 SAM/ADA，则单位被摧毁；若目标是地面部队的 Embedded Flak，则压制防空能力，不摧毁整个地面部队。

Wild Weasel 作用范围更广，影响整个 Megahex 并持续到 End Phase，但不直接把区内防空单位一律消灭。它还要求该区无敌方制空、W 中队存活且有未损坏步。玩家可能先争夺制空区，再做 Wild Weasel，随后安排多次打击；仍须遵守各项任务时机和中队一次任务限制。

来源：§24.11–24.12；§4 的 Removal、End Phase。

### 18.8 示例：航空支援与地面电子战

假设一支地面部队战斗值 15，两支成功完成 Ground Support 的中队 Strike 为 4、3，空中支援贡献为 7，使合计为 22，之后继续执行其他地面战斗修正与结算。

若敌方地面 EW 成功，按规则把航空支援减半，则 7 变为 3，地面加航空成为 18。这里不把地面单位 15 一起减半，也不消灭支援中队；改变的是它们对这场地面战的有效贡献。

与 NATO 常规空袭相比，1985 的 Ground Support 直接增加己方战斗值，NATO 的空袭通常先造成敌方战损、混乱或压制。两款游戏都能让航空兵帮助地面攻击，但数值进入战斗的方式不同。

来源：§3.4、9.15、24.9。

### 18.9 示例：直升机的往返移动力与 NOE

假设一支运输直升机有 **24 MP**，从己方野外基地飞到 6 格外装载一支部队，再飞 6 格回基地卸载；无额外 LOC 或舰艇成本。

- 正常飞行：`6 + 3装载 + 6 + 3卸载 = 18 MP`，可以完成。
- 全程 NOE：`18 + 3 + 18 + 3 = 42 MP`，超过 24，不能照这个计划完成。
- 混合飞行：可以只在危险路径部分使用 NOE，但所有飞行、装卸、返回成本都计入同一任务总 MP。

NOE 缩小地面防空射程，却降低能完成的往返距离。如果要取得进入敌制空区的 NOE 修正，须在该区内整个移动期间维持 NOE；不能只在入区瞬间切换，然后在区内恢复正常飞行却保留修正。

NATO 的“去程最多 10 格、返程最多 10 格”与这个总 MP 模型不同：不能拿 1985 的移动值简单除以二，就当成 NATO 的单航段距离。

来源：§16.2、25.3–25.6。

### 18.10 示例：空运损失与长期保障

假设运输机起始总运力 6，搭载的部队起始运输成本也是 6。途中运输机被击毁一步，先按 Air Transport 规则对乘客施加一步损失；再按该部队规模重新计算运输成本，与幸存运力比较。若仍装不下，必须继续减少乘客战力步，不能让剩余运输机承载超额乘客。

如果这次使用 Strategic Airlift，原来有 5 战略空运点，其中代表运输机的一步被击毁，以后回合能力永久下降至 4；下回合 Assets 重置不会把它自动补回 5。普通飞机的 Damage 可按机场修理恢复，战略运力“被击毁”的永久削减不能用一次普通飞机修理替代。

人员空运成功解除 Equipment Only 后，单位当回合仍不能移动。这代表人装结合、整备需要时间，并不是空运成功就立即获得一支可发动地面突击的机械化部队。

来源：§24.14–24.15、24.23、26.4.2。

## 19. 常见误读与决策差异

### 19.1 同名术语不一定表示同一规则

| 易混淆概念 | 应如何理解 |
| --- | --- |
| NATO 的 Airspace 与 1985 的 Air Superiority Area | 前者是地面供应态势投射出的空域分类；后者是中队争夺获得的本回合制空区 |
| 1985 的 National Air Space 与制空区 | 外国领空准入是外交问题，制空优势是作战问题；有优势不能自动无视中立国许可 |
| 两款游戏的 Interception | NATO 是运输步/Command 损失检定；1985 是飞机接敌、护航交战、攻击 Strike 的任务链 |
| 两款游戏的 Ferry | NATO 运的是地面部队、可能受运输拦截；1985 转移的是航空中队，不能被空中截击 |
| 空运和空降 | 空运通常是基地/安全地点之间运输，空降允许特定部队落到野外；1985 的空降仍不能直接落敌军格 |
| Ground Support 与 Ground Strike | 1985 前者给己方地面战斗加值，后者先攻击敌人、设施或移动能力 |
| SEAD 与 Wild Weasel | SEAD 针对指定防空/舰艇，可压制或摧毁；Wild Weasel 改变整个区域防空效果，须 W 能力 |
| Damage、Destroyed、Abort | 可修理损坏、永久步损、任务中止是不同结果；不能把中止一律算成击落 |
| 航空点与中队 | NATO 一个点能打最多两地面战力步，不等于一架飞机、一中队或两飞机步 |
| 常规航空点与核化资源 | NATO 核武独立，北约战术化武额外消耗航空点；1985 核投送依赖合资格中队和脉冲配额 |

以上均是对前文规则的对照，不新增规则或任务。

### 19.2 NATO 的主要决策

NATO 玩家主要决定**把有限打击效果用在哪里、何时使用，以及是否冒险运输部队**。空域随着前线与补给变化，因此包围、切补给、占城市不仅改变地面战，也会改变战术航空点覆盖和运输风险。

北约需要在即刻削弱华约进攻、保留点数支撑自己反攻、压制 HQ 和削减未来补给之间取舍。华约必须在自己的打击段预先投入，不能等北约攻击发生再临时呼叫防御空袭。运输 Command 的永久损失还会使以后空降或机降的选择减少。

这是根据规则结构作出的分析：航空行动的重点是地面战役的资源分配与时机，游戏把复杂的战斗机、远程防空和机场出动体系压缩成可直接用于地面作战的能力。

### 19.3 1985 的主要决策

1985 玩家除了选择目标，还要组织**中队、基地、护航、防空压制与任务顺序**。把优秀战斗机放进制空区，可能获得多次截击/护航机会，但它们先要承受制空战消耗，而且制空区数量有限。

一次地面打击可能需要其他中队先侦察、做 SEAD 或 Wild Weasel。有限的 ECM 和 AEW 应该分配给哪些任务、是否值得通过延伸航程降低打击能力、是否必须冒险使用战略运输资源，都属于独立决策。地面进攻也可以通过占领或损坏机场削弱对方航空体系；航空行动反过来保护地面、阻断补给、打击海军。

这是根据规则结构作出的分析：空战胜负并不只取决于最强中队的攻击值，还取决于何时能起飞、能否找到目标、有没有护航和压制、有没有运力与补给，以及损坏后能否恢复。
